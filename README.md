## ⚡ Tech Stack & Architecture
- **Framework:** Next.js 15.4 (App Router)
- **UI & Components:** React 19.2 + TypeScript 5.9
- **Styling:** Tailwind CSS 4.1 + Modern Responsive Grid & Flexbox
- **Typography:** Self-hosted `Cormorant Garamond` (Luxury Serif) & `Plus Jakarta Sans` via `next/font/google`
- **Animations:** Hardware-accelerated Motion 12.2 + Lenis Smooth Momentum Scroll
- **Image Pipeline:** High-Fidelity AVIF & WebP Next-Gen Formats (-72% Transfer Weight)
- **AI Integrations:** Google Gemini AI Consultation Atelier & Real-Time Concierge
- **Maps:** Google Maps Platform Embed in Place Mode with strict-origin fallback
